# Study-grouped assay-disagreement generalization protocol

## Scope and evaluation status

This phase tests whether the assay-disagreement model generalizes to unseen publications. The 2020+ evaluation cohort is locked by code and is never used for feature selection, model selection, fitting, or calibration. Its aggregate results were inspected in the preceding phase, however, so this is not an analyst-blinded external replication. That limitation is reported explicitly.

## Leakage prevention

Each compound event compares exact normalized IC50 evidence from earlier publications with the median in its latest publication year. Earlier and held-out activity IDs, assay IDs, and document IDs are disjoint and remain within one prespecified target/organism/endpoint/assay-type/BAO context. Records flagged by ChEMBL as potential duplicates or carrying validity problems are excluded.

Development contains held-out studies through 2019. Evaluation begins in 2020. Any molecule appearing in evaluation for any target is removed from development for all targets. Natural-product annotations are used only for subgroup analysis.

Every development prediction is generated by leaving its complete ChEMBL publication group out of model fitting. Probability calibration is itself cross-fitted by publication group. The selection criterion is the lowest equal-study-weighted Brier score, so a large compound series cannot dominate model choice.

## Prespecified candidates

- Development-prevalence baseline.
- The existing full L2 logistic model.
- Cross-fitted calibration of that model.
- Compact history/provenance logistic regression.
- Compact molecular/history/provenance logistic regression.
- A shallow, strongly regularized histogram gradient-boosting comparator.

The compact feature set contains RDKit physicochemical descriptors, aromatic/heteroatom fractions, molecular complexity, and summaries of evidence available before the future experiment: robust dispersion, document/assay counts, temporal trend, recent historical shift, and fixed assay-description keyword fractions. It excludes future values, future assay/document identifiers, the disagreement label, and natural-product status.

No candidate or hyperparameter is selected using 2020+ outcomes. If learned candidates do not beat prevalence on study-grouped development Brier score, the pipeline selects the prevalence fallback instead of choosing a favorable evaluation result.

## Evaluation

The locked evaluation reports AUROC, PR-AUC, Brier score, log loss, expected calibration error, calibration intercept/slope, and study-clustered confidence intervals. Paired confidence intervals compare the development-selected method with the prior full model. Sensitivity outputs include:

- leave-one-study-out development predictions;
- metrics after removing each evaluation publication;
- a dedicated CHEMBL5729139 analysis;
- binary outcome intraclass correlation by publication;
- natural-product compound errors and feature-distribution shifts;
- descriptor-domain nearest-neighbor diagnostics;
- development-study bootstrap intervals for selected risks.

## Reproduction

```powershell
cd backend
python -m app.pipeline assay-disagreement-generalization `
  --specs ../experiments/multitarget_targets.json `
  --output-dir ../experiments/assay_disagreement_generalization `
  --bootstrap-iterations 1000 `
  --prediction-interval-iterations 200 `
  --seed 2026
```

The serialized artifact records the selected fallback/model, feature contract, calibration object, validation status, and limitations. A failed model is not promoted as a validated predictor.

## Interpretation limits

Publication is an imperfect study proxy. ChEMBL lacks uniformly structured substrate, construct, detection, incubation, and laboratory fields. Most development publications contribute one compound, only five human targets are represented, and the natural-product subgroup is small and target-confounded. Assay disagreement does not establish biological failure, efficacy, safety, or clinical relevance.
